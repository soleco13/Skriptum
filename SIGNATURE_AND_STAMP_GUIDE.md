# Руководство по использованию функций подписи и печати

## Обзор реализованных функций

В редактор документов были успешно добавлены две новые функции:

### 1. Ручная подпись (Signature Pad)
- **Компонент**: `SignaturePad.vue`
- **Библиотека**: `signature_pad`
- **Функции**:
  - Рисование подписи с помощью мыши или касания
  - Очистка подписи
  - Отмена последнего штриха
  - Сохранение подписи в формате base64
  - Предпросмотр сохраненной подписи

### 2. Электронная печать (Digital Stamp)
- **Компонент**: `DigitalStamp.vue`
- **Функции**:
  - Форма с полями: Организация, Сертификат, Издатель, Период действия
  - Предпросмотр печати с синей рамкой и текстом
  - Генерация изображения печати через Canvas API
  - Сохранение печати в формате base64
  - Скачивание печати

## Как использовать

### Подпись документа
1. Откройте документ в редакторе
2. Нажмите кнопку "Подпись" в панели действий
3. Нарисуйте подпись в области canvas
4. Нажмите "Сохранить подпись"
5. Статус документа автоматически изменится на "Утверждено"

### Проставление печати
1. Откройте документ в редакторе
2. Нажмите кнопку "Печать" в панели действий
3. Заполните форму с данными печати
4. Нажмите "Предпросмотр" для генерации печати
5. Нажмите "Сохранить печать"
6. Статус документа автоматически изменится на "Утверждено"

## Технические детали

### Backend изменения
- **Модель Document**: добавлены поля для подписи и печати
- **API эндпоинты**: 
  - `POST /documents/{id}/add_signature/` - добавление подписи
  - `POST /documents/{id}/add_stamp/` - добавление печати
  - `GET /documents/{id}/signature_info/` - информация о подписи
  - `GET /documents/{id}/stamp_info/` - информация о печати
  - `GET /documents/{id}/approval_status/` - статус утверждения

### Frontend изменения
- **Компоненты**: SignaturePad.vue, DigitalStamp.vue
- **Интеграция**: добавлены в DocumentEdit.vue
- **API сервисы**: обновлен DocumentService

### База данных
- **Миграция**: 0013_document_digital_stamp_document_signature_and_more.py
- **Новые поля**:
  - `signature` - подпись (base64)
  - `signature_date` - дата подписи
  - `signed_by` - кто подписал
  - `digital_stamp` - печать (base64)
  - `stamp_data` - данные печати (JSON)
  - `stamp_date` - дата проставления печати
  - `stamped_by` - кто проставил печать

## Автоматическое изменение статуса

При подписи или проставлении печати статус документа автоматически изменяется на "Утверждено" (approved).

## Права доступа

Пользователи могут подписывать и проставлять печати на документах, если:
- Они являются владельцами документа
- У них есть права администратора или редактирования на документ
- У них есть соответствующая роль в системе

## Безопасность

- Подписи и печати сохраняются в формате base64
- Добавлена проверка прав доступа
- Ведется журнал кто и когда подписал/проставил печать
- Данные печати сохраняются в JSON формате для аудита
