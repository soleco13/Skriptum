# Skriptum (DjVu)

Skriptum - это система управления документами и бизнес-процессами, разработанная с использованием Django (бэкенд) и Vue.js (фронтенд). Система предоставляет возможности для создания, редактирования и управления документами, задачами и бизнес-процессами с поддержкой BPMN-диаграмм.

## Обзор

Skriptum - это комплексное решение для управления документами и бизнес-процессами, которое позволяет пользователям создавать, редактировать и управлять документами с помощью встроенного редактора CKEditor, отслеживать версии документов, управлять задачами и бизнес-процессами, а также создавать и редактировать BPMN-диаграммы.

## Функциональные возможности

- **Управление документами**:
  - Создание и редактирование документов с помощью CKEditor
  - Загрузка и хранение файлов различных форматов
  - Контроль версий документов
  - Восстановление предыдущих версий документов
  - Цифровые подписи и печати
  - Управление доступом к документам

- **Управление задачами**:
  - Создание и назначение задач
  - Отслеживание статуса и приоритета задач
  - Установка сроков выполнения
  - Уведомления о назначении и изменении задач

- **Управление бизнес-процессами**:
  - Создание и редактирование BPMN-диаграмм
  - Отслеживание прогресса выполнения процессов
  - Управление участниками процессов
  - Управление доступом к BPMN-диаграммам

- **Система уведомлений**:
  - Реальное время уведомления через WebSocket
  - Уведомления о создании/изменении документов, задач, процессов
  - Уведомления о предоставлении/отзыве доступа
  - Уведомления о назначении задач
  - Интерактивный колокольчик уведомлений
  - Страница управления уведомлениями с фильтрацией
  - Возможность пометить как прочитанные/удалить уведомления

- **Управление ролями и пользователями**:
  - Гибкая система ролей и разрешений
  - Управление доступом к функциям системы
  - Профили пользователей с настройками

- **Пользовательский интерфейс**:
  - Современный адаптивный дизайн
  - Панель управления с основными метриками
  - Глобальный поиск
  - Оптимизированный интерфейс без лишних элементов
  - Интуитивная навигация

## Технологический стек

### Бэкенд

- **Django** - основной фреймворк для разработки бэкенда
- **Django REST Framework** - для создания RESTful API
- **Djoser** - для аутентификации и авторизации
- **PostgreSQL** - база данных
- **Django CKEditor 5** - для редактирования документов
- **Django Channels** - для WebSocket соединений и реального времени
- **Memurai** - Redis-совместимый брокер сообщений для Windows
- **Daphne** - ASGI сервер для WebSocket поддержки

### Фронтенд

- **Vue.js 3** - основной фреймворк для разработки фронтенда
- **Vue Router** - для маршрутизации
- **Axios** - для HTTP-запросов
- **CKEditor 5** - для редактирования документов
- **BPMN.js** - для создания и редактирования BPMN-диаграмм
- **Vue Toastification** - для всплывающих уведомлений
- **WebSocket API** - для реального времени уведомлений

## Установка и запуск

### Бэкенд (Django)

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd DjVu
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # для Windows
   # source .venv/bin/activate  # для Linux/Mac
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настройте базу данных PostgreSQL:
   - Создайте базу данных `skriptum`
   - Настройте параметры подключения в `dip/dip/settings.py`

5. Установите и настройте Memurai (Redis для Windows):
   - Скачайте и установите Memurai с официального сайта
   - Запустите Memurai на порту 6379 (по умолчанию)

6. Примените миграции:
   ```bash
   cd dip
   python manage.py migrate
   ```

7. Создайте суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```

8. Запустите сервер с поддержкой WebSocket:
   ```bash
   # Для разработки с WebSocket поддержкой
   python -m daphne -b 0.0.0.0 -p 8000 dip.asgi:application
   
   # Или обычный сервер разработки (без WebSocket)
   python manage.py runserver
   ```

### Фронтенд (Vue.js)

1. Перейдите в директорию фронтенда:
   ```bash
   cd front
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run serve
   ```

4. Для сборки проекта:
   ```bash
   npm run build
   ```

## API

Система предоставляет RESTful API для взаимодействия с бэкендом. Основные эндпоинты:

### Основные ресурсы
- `/api/documents/` - управление документами
- `/api/processes/` - управление бизнес-процессами
- `/api/tasks/` - управление задачами
- `/api/users/` - управление пользователями
- `/api/bpmn-diagrams/` - управление BPMN-диаграммами
- `/api/roles/` - управление ролями и разрешениями

### Система уведомлений
- `/api/notifications/` - управление уведомлениями
- `/api/notifications/recent/` - получение последних уведомлений
- `/api/notifications/unread_count/` - количество непрочитанных
- `/api/notifications/{id}/mark_as_read/` - пометить как прочитанное
- `/api/notifications/mark_all_as_read/` - пометить все как прочитанные
- `/api/notifications/clear_all/` - удалить все уведомления

### WebSocket соединения
- `ws://localhost:8000/ws/notifications/` - WebSocket для уведомлений в реальном времени

### Аутентификация
Для аутентификации используется JWT-токены:

- `/auth/jwt/create/` - получение токена
- `/auth/users/` - регистрация пользователя
- `/auth/users/me/` - получение информации о текущем пользователе

## Система уведомлений

Skriptum включает в себя мощную систему уведомлений в реальном времени, которая обеспечивает мгновенное информирование пользователей о важных событиях в системе.

### Возможности системы уведомлений

- **Уведомления в реальном времени** через WebSocket соединения
- **Автоматические уведомления** при создании/изменении документов, задач, процессов
- **Уведомления о доступе** при предоставлении/отзыве прав доступа
- **Интерактивный интерфейс** с колокольчиком уведомлений
- **Фильтрация и поиск** уведомлений
- **Управление уведомлениями** (прочитать, удалить, очистить все)

### Типы уведомлений

- **Документы**: создание, изменение, предоставление/отзыв доступа
- **Задачи**: назначение, изменение статуса, дедлайны
- **Процессы**: создание, изменение, предоставление/отзыв доступа
- **BPMN-диаграммы**: создание, изменение, предоставление/отзыв доступа

### Технические детали

- **Backend**: Django Channels + Memurai (Redis)
- **Frontend**: WebSocket API + Vue.js компоненты
- **Аутентификация**: JWT токены для WebSocket соединений
- **Масштабируемость**: Группировка пользователей по каналам

## Авторизация и аутентификация

Система использует JWT-токены для аутентификации пользователей. Токены хранятся в localStorage или sessionStorage браузера и автоматически добавляются к каждому запросу к API.

Для регистрации новых пользователей используется Djoser, который предоставляет готовые эндпоинты для регистрации, входа и управления пользователями.

### Система ролей и разрешений

- **Гибкая система ролей** с настраиваемыми разрешениями
- **Управление доступом** к функциям системы
- **Контроль доступа** к документам и процессам
- **Административная панель** для управления ролями
